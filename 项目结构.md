## 📦 构建与部署

```bash
# 1. 前端构建
cd frontend
npm install
npm run build          # 产物 → frontend/dist/

# 2. 后端打包（在 jkstore_new/ 下执行）
cd jkstore_new
mvn clean package -DskipTests

# 3. 运行（唯一入口）
java -jar app/target/oneflow-app-1.0.0-SNAPSHOT.war
# 默认端口 :8877，可通过环境变量 PORT=8887 修改
```

## ➕ 如何添加新业务模块

1. 在 `jkstore_new/` 下新建目录 `你的项目/`
2. 创建 `pom.xml`，parent 指向 `jkstore_new`，`groupId` 和包名用你自己的
3. 写 controller/service/repository 等业务代码
4. 父 `jkstore_new/pom.xml` 的 `<modules>` 加上新模块
5. `app/pom.xml` 的 `<dependencies>` 加上新模块
6. `app/OneFlowApplication.java` 的 `scanBasePackages` 加上你的包名
7. ✅ 完成，路由自动注册到同一端口
